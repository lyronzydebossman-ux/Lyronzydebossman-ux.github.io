Field notes

METHOD LOG
// 01

Remote before real

Every site starts as a Sentinel-2 composite — NDVI, NDWI, and bare soil index layered before a single boot touches ground. Patterns found here decide where fieldwork actually goes.

// 02

Ground-truth or it didn't happen

Satellite signal gets checked against household surveys, GPS transects, and photographs at fixed bearings. Anything the imagery implies has to survive contact with the actual place.

// 03

Change is the only constant

Single dates tell you almost nothing. Every catalogued site here is read as a time-series — 2000 to present — because land only means something in motion.
